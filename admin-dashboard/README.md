# لوحة التحكم الإدارية لخالة العيال

## بنية المشروع
- المشروع هو فرع فرعي من المشروع الرئيسي
- يهدف إلى إدارة جميع جوانب التطبيق من قبل المشرفين
- مبنى على React + TypeScript + Vite + Tailwind CSS

## المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn أو bun

## التثبيت
1. أدخل مجلد `admin-dashboard`
2. أنشئ ملف `.env` وقم بنسخ محتويات `.env.example` إليه
3. أضف بيانات Supabase الخاصة بك إلى ملف `.env`
4. قم بتثبيت التبعيات باستخدام `npm install` أو `bun install`
5. قم بتشغيل الخادم المحلي باستخدام `npm run dev` أو `bun run dev`

## الأقسام المتاحة
1. الإحصائيات الرئيسية
2. إدارة الخالات
3. التحقق الأمني للعملاء
4. الحسابات المالية والتحليلات
5. الإعدادات
